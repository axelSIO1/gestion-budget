# Gestion Budget Étudiant

## Présentation

Application web permettant à un étudiant de suivre ses dépenses et revenus par catégorie, afin de garder une vue claire sur son budget.

## Objectif

De nombreux étudiants n'ont pas de vue d'ensemble claire sur leurs finances. Cette application centralise le suivi des transactions (dépenses/revenus) pour éviter les mauvaises surprises en fin de mois.

## Fonctionnalités principales

- Inscription / connexion
- Ajouter, modifier, supprimer une transaction
- Filtrer les transactions par mois / catégorie
- Consulter son solde total
- (Bonus) Graphiques, budget par catégorie avec alertes, export

## Technologies envisagées

- Frontend : HTML / CSS / JavaScript
- Backend : Java (Spring Boot)
- Base de données : PostgreSQL (accès via JDBC)
