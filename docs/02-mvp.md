# MVP (Minimum Viable Product)

## Fonctionnalités obligatoires

MVP

[ ] inscription / connexion
[ ] afficher les transactions
[ ] ajouter une transaction
[ ] modifier une transaction
[ ] supprimer une transaction
[ ] filtrer par mois / catégorie
[ ] afficher le solde total

## Fonctionnalités bonus

BONUS

[ ] graphiques (répartition par catégorie, évolution du solde)
[ ] budget mensuel par catégorie avec alerte de dépassement
[ ] export CSV / PDF
[ ] dépenses récurrentes automatiques
[ ] mode "colocation" (dépenses partagées entre plusieurs comptes)

Règle : MVP avant BONUS.
